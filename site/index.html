XPath to UiSelector

Appium Android XPath in, UiAutomator2 UiSelector out, or the reason there is none. Runs in your browser with the same code as the npm package.

npm GitHub Reference
Examples:
exact: same elements, same order. close: converts, with a warning about a difference. skipped: no exact UiSelector; the hint says how to rewrite it by hand. loose: simpler, wider forms, each with a warning: textContains / textStartsWith ignore case, a direct child becomes childSelector, translate() becomes (?i). Exact for the default UiAutomator2 driver settings only. UiSelector is planned for removal upstream.
