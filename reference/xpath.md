# XPath as evaluated by the server (PsychoPath, XPath 2.0)

Files under the server's `vendor/org.eclipse.wst.xml.xpath2.processor/src/org/eclipse/wst/xml/xpath2/processor/`.
Only what real locators use; everything else is skipped by the converter's whitelist.

| Id | Fact | Source | For the converter |
| --- | --- | --- | --- |
| XP-01 | XPath 2.0 functions are available: `contains`, `starts-with`, `ends-with`, `matches`, `lower-case`, `upper-case`, `translate`, `normalize-space`, `string-length`, `concat`, `substring*`, `replace`, `tokenize`, `count`, `position`, `last`, `not`, `true`, `false`, … | `function/FnFunctionLibrary.java` | Accept these names in the parser; convert only the rows below |
| XP-02 | `contains`, `starts-with`, `ends-with` compare code points (default collation); an absent attribute is `""` | `internal/function/FnContains.java`, `FnEndsWith.java` | With a non-empty literal: exact as an escaped `…Matches` regex. With `""`: true for every element: the test is dropped |
| XP-03 | `matches(s, p, flags)` compiles `p` as a Java regex with `UNIX_LINES` (+ `s`/`m`/`i`/`x` → `DOTALL`/`MULTILINE`/`CASE_INSENSITIVE`/`COMMENTS`) and is true if `find()` succeeds anywhere; `-[` is rewritten to `&&[^`; an absent attribute is `""` | `internal/function/FnMatches.java`, `AbstractRegExFunction.java` | `…Matches("(?d)(?s:.*)(?flags:p)(?s:.*)")` is the same test for a non-null value, with `-s` added to the flags when `s` is not among them (`textMatches` / `descriptionMatches` compile with DOTALL, SEL-03); a pattern that matches `""` also matches absent attributes in XPath: skip it |
| XP-04 | `i` without `UNICODE_CASE` is ASCII-only case folding | `AbstractRegExFunction.compileAndExecute` | Keep `(?i)` as is; do not add `u` |
| XP-05 | `lower-case`, `upper-case` use Java case mapping (full Unicode); `translate` maps listed characters only | `FnLowerCase.java`, `FnUpperCase.java`, `FnTranslate.java` | `lower-case(@a)="v"` vs. `(?i)`: differs on non-ASCII (e.g. Kelvin sign). **Oracle:** Android regexes are ICU, so `(?i)` folds Unicode letters: `lower-case` agreed with `(?i)` (Kelvin sign included); `upper-case` and `translate` did not (the Kelvin sign). Decision 3: `lower-case` close, `upper-case` skip. `translate(@a, F, T) = "v"` is exact as a regex with each character of `v` as the class of the characters `translate` maps to it (deleted characters as `[…]*` between them): the Kelvin sign maps to nothing listed |
| XP-06 | General comparison `@a=("x","y")` is true if any value matches; `@a=1` compares numerically (untyped → double) | XPath 2.0 general comparison | Sequence of strings → one regex alternation (exact); a numeric literal on a text attribute: skip (`"1.0"` = 1) |
| XP-07 | `text()` selects text nodes; the server's XML has none | XML from SRV-04 | `text()` matches nothing: skip with a reason |
| XP-08 | `(expr)[n]` is the n-th node of the whole result in document order; `expr[n]` inside a step is the position among the step's matches under each parent | XPath 2.0 | `(//X)[n]` → `instance(n-1)` (SEL-10); `//X[n]`: skip |
| XP-09 | `|` / `union` merges node sets in document order | XPath 2.0 | No UiSelector equivalent (SRV-21): skip, except same-step unions that fold into one regex. A branch (or an `or` side) that tests an attribute the Android page source never writes (`@id`, `@label`, …) matches nothing and drops out |
| XP-10 | `normalize-space(s)` strips leading and trailing XML whitespace (space, tab, CR, LF) and collapses each run to one space; `string-length(s)` counts code points; both read an absent attribute as `""` | `FnNormalizeSpace.java`, `FnStringLength.java` | `normalize-space(@a)="v"` → `…Matches` with `[ \t\n\r]*` around `v` and `[ \t\n\r]+` for each space in it (exact); `string-length(@a)=n` → `…Matches("[\s\S]{n}")` (one code point each; with DOTALL ICU's `.` takes CR LF as one), close on `@text` from n = 3, the length of the shortest float string |
| XP-11 | `if (C) then A else B`; `some $v in E satisfies B` is true if B holds for an item of E, `every` if it holds for all (true for an empty E) | XPath 2.0 | `if (C) then true() else false()` → C, the other way round → `not(C)`; `some $v in @a satisfies B` → `@a and B` with `$v` → `@a` (an attribute is one value or none); `every`: skip |
